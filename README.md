# Shorya Gupta — Luxury Portfolio

A responsive dark, neon-blue/red developer portfolio inspired by the visual style in the reference reel.

## Preview locally
Open `index.html` in a browser. The page uses Google Fonts, so an internet connection improves typography.

## Publish with GitHub Pages
1. Create a new repository, e.g. `shorya-portfolio`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. After GitHub Pages publishes it, link the website from your GitHub profile README.

## Personalize before publishing
- Verify the project descriptions in `index.html`.
- Add your own photo if you want one; the current hero uses a designed SG monogram rather than someone else's portrait.
- Add links to real repositories and social profiles you want to share.
- The numeric dashboard is intentionally illustrative, not live GitHub statistics.
